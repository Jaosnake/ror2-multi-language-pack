# Changelog

## 1.0.3
- Updated translations for **Red_Alert 3.3.10**: added Chrono Legionnaire's full logbook lore, corrected his subtitle ("Never Existed") and mastery achievement, added color loadout labels, and updated Tesla Trooper and Desolator skill descriptions and values to match the current mod.
- Added Esperanto (`eo`) and Latin (`la`), expanding support to 15 languages (Ukrainian, Esperanto, and Latin require the optional [P.E.L.E](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) mod).
- Fixed text formatting glitches, achievement names, and mistranslated or outdated tooltips across supported languages, and removed duplicate legacy files.

## 1.0.2
- Add Chrono Legionnaire language files for every supported language.
- Fixed mojibake, accent issues, language tokens, and untranslated English fallbacks.
- Rebuilt the R2API.Language package for manual Thunderstore upload.

## 1.0.1
- Fixed credits that were polluting the interface due to an error during file upload.
