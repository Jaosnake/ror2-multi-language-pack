# 🌍 Jaosnake-SwanSongExtended_LanguagePack

Multi-language translation pack for **SwanSongExtended** (`RiskOfBrainrot-SwanSongExtended`) by **RiskOfBrainrot** (v1.1.3).

---

### 🇧🇷 Recomendação do P.E.L.E
Para compatibilidade completa com todos os recursos e suporte a idiomas adicionais como Ucraniano (`UA`/`uk`), Esperanto (`eo`) e Latim (`la`), recomendamos a instalação do [P.E.L.E (Language System)](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) (opcional para este mod).

### 🇺🇸 P.E.L.E Recommendation
For complete compatibility with all language features and support for Ukrainian (`UA`/`uk`), Esperanto (`eo`), and Latin (`la`), we recommend installing [P.E.L.E (Language System)](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) (optional for this mod).
