Brazilian Portuguese (`pt-BR`) translation pack for **Starstorm 2** (`v0.6.47`) by **TeamMoonstorm**.

> 🇧🇷 Este pacote inclui a tradução completa em **Português (Brasil)** sincronizada com o **Starstorm 2 v0.6.47**, mantendo a compatibilidade com os marcadores dinâmicos do mod.
>
> 💡 **Sobre o P.E.L.E (opcional):** Para jogar em **Português (Brasil)**, este pacote funciona diretamente apenas com `R2API_Language` — o [P.E.L.E](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) é **opcional** e serve para quem deseja jogar em **ucraniano, esperanto ou latim**.
>
> 💡 **About P.E.L.E (optional):** For **Brazilian Portuguese**, this pack works directly with `R2API_Language` — [P.E.L.E](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) is **optional** and is only needed if you want to play in **Ukrainian, Esperanto, or Latin**.

## 📥 Instalação Manual / Manual Installation
1. Instale **Starstorm 2** (`0.6.47`) e **R2API_Language**.
2. Baixe este pacote.
3. Copie a pasta `Jaosnake-Starstorm2_ptBR_LanguagePack` para `BepInEx/plugins/`.
4. No jogo, selecione **Português (Brasil)**.

Este pacote contém apenas arquivos de tradução e não modifica o código do Starstorm 2.
