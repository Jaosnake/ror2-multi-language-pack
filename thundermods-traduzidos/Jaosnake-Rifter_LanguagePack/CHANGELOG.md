# Changelog

## 1.0.3
- Updated dependency and rebuilt all 27 active tokens directly against `Hippo-Rifter 2.0.0` (`RifterMod.dll`) full kit rework.
- Updated reworked descriptions and values: `Shatter` (stops enemies and reduces armor by 30 for 3s), `Focused Rift` (`300% - 500%`), `Convergent Rifts` (6 rifts for `100%` each, ignores terrain), `Wandering Rift` (`300%` / `600%`), `Slipstream` (backwards vortex + invulnerability up to 3s), and `Timelock` (`500%`).
- Added translation for the `Crushing` (`120%` per enemy hit) keyword tooltip and fixed Mastery achievement token casing (`ACHIEVEMENT_BLAKE_RIFTER_MASTERYACHIEVEMENT_*`).
- Added Esperanto (`eo`, x-system) and Latin (`la`), expanding coverage to 15 languages.
- Removed duplicate legacy `*-Rifter.language` files and standardized README, manifest, and icon.

## 1.0.2

- Rebuilt the R2API.Language package for manual Thunderstore upload.
