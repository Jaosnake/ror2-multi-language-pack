# Changelog

## 1.0.0
- Initial release.
- Added 15-language translation pack for Drow Ranger survivor mod (`DDL-DrowRanger` v0.4.0):
  - English (`en`), Portuguese (`pt-BR`), Spanish Latin America (`es-419`), Spanish Spain (`es-ES`), French (`FR`), Italian (`IT`), German (`de`), Russian (`RU`), Ukrainian (`UA`), Japanese (`ja`), Korean (`ko`), Chinese Simplified (`zh-CN`), Turkish (`tr`).
  - Native P.E.L.E support for Classical Latin (`la`) and Esperanto (`eo`).
- 100% tag balance, canonical token mappings and dynamic stat formatting.
