# 🌍 Jaosnake-Sandswept_ptBR_LanguagePack

![Version](https://img.shields.io/badge/%F0%9F%97%82%EF%B8%8F%20Version-1.0.3-blue)
![R2API](https://img.shields.io/badge/%F0%9F%93%A6%20R2API__Language-required-ff69b4)

Tradução dedicada em **Português (Brasil)** para o mod **Sandswept** (`1.4.6`), criado por **SandsweptTeam**.

> Se você procura tradução em outros idiomas além do Português do Brasil, utilize o pacote multilíngue [Jaosnake-Sandswept_LanguagePack](https://thunderstore.io/c/riskofrain2/p/Jaosnake/Sandswept_LanguagePack/) (instale apenas um dos dois pacotes).

---

### 🇧🇷 Nota sobre o P.E.L.E (Opcional)
Este pacote funciona diretamente com **R2API_Language** para jogar em **Português (Brasil)** — o [P.E.L.E](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) é **opcional** e serve para quem deseja jogar em idiomas adicionais como Ucraniano (`UA`), Esperanto (`eo`) ou Latim (`la`).

### 🇺🇸 Note about P.E.L.E (Optional)
This pack works directly with **R2API_Language** for **Brazilian Portuguese** — [P.E.L.E](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) is **optional** and is intended for players who want additional languages such as Ukrainian (`UA`), Esperanto (`eo`), or Latin (`la`).

## 📥 Instalação Manual
1. Instale **Sandswept** (`1.4.6`) e **R2API_Language** (`1.1.0`).
2. Baixe e extraia este pacote.
3. Copie a pasta `Jaosnake-Sandswept_ptBR_LanguagePack` para `BepInEx/plugins/`.
4. No jogo, selecione **Português (Brasil)** nas opções de idioma.

Este pacote contém apenas arquivos de tradução para `R2API.Language` e não modifica o código do Sandswept. Valores numéricos e atalhos refletem a configuração padrão do Sandswept `1.4.6`.
