# 🌍 Jaosnake-Heretic_LanguagePack

![Version](https://img.shields.io/badge/Version-1.0.4-blue)
![R2API](https://img.shields.io/badge/R2API__Language-required-ff69b4)

Multi-language translation pack for **Heretic** by **Moffein**.

Version 1.0.4 revises the character passive, Mark of Heresy, replacement skills, and unlock text across the included languages. It preserves the original skill values and the achievement name.

## 📦 Dependencies

| Package | Minimum version |
|---|---|
| Moffein-Heretic | `1.2.10` |
| RiskofThunder-R2API_Language | `1.1.0` |

## 🌐 Languages

English, German, Spanish (Latin America and Spain), French, Italian, Japanese, Korean, Portuguese (Brazil), Russian, Turkish, Ukrainian, and Simplified Chinese.

Ukrainian may require a compatible language selector such as P.E.L.E.
