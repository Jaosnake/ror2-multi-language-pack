# Drow Ranger Multi-Language Pack (15 Languages)

Adds comprehensive translations across 15 languages for **Drow Ranger** (`DDL-DrowRanger`):
- English (`en`)
- Portuguese (Brazil) (`pt-BR`)
- Spanish (Spain) (`es-ES`)
- Spanish (Latin America) (`es-419`)
- French (`FR`)
- Italian (`IT`)
- German (`de`)
- Russian (`RU`)
- Ukrainian (`UA` / `uk`)
- Latin (`la` via P.E.L.E)
- Esperanto (`eo` via P.E.L.E)
- Chinese Simplified (`zh-CN`)
- Japanese (`ja`)
- Korean (`ko`)
- Turkish (`tr`)

Includes full support for P.E.L.E (Prompt Expanded Language Engine) and R2API.Language.
