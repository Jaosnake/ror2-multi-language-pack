## 🎮 What is Translated
- **Survivor Identity**: Sniper ("Eagle Eye"), tips, and character description.
- **Lore Log**: Full backstory of the Sniper survivor on Petrichor V.
- **Outro Messages**: Outro victory flavor (*"..and so they left, the sound still ringing in deaf ears."*) and failure flavor.
- **Full Ability Suite**:
  - **Primary**: Snipe & Reload, Mark (Alt 1), Hard Impact (Alt 2 - Mortar).
  - **Secondary**: Steady Aim (charging zoom & critical weakpoint targeting), Heavy Steady Aim.
  - **Utility**: Military Training (backflip roll), Combat Training (combat slide).
  - **Special**: Send Spotter, Spotter: FEEDBACK, Spotter: RECHARGE.
  - **Keywords**: Weakpoint, Reload, Headshot, Stun, Mortar.
- **Unlocks & Achievements**: Mastery skin ("Hired Gun") and Mastery achievement.

## 📥 Installation
1. Install [Thunderstore Mod Manager](https://www.overwolf.com/app/Thunderstore-Thunderstore_Mod_Manager) or [r2modman](https://github.com/ebkr/r2modmanPlus).
2. Install **EnforcerGang-SniperClassic** and **R2API_Language**.
3. Install **Jaosnake-SniperClassic_LanguagePack**.
4. Launch the game in your preferred language!
