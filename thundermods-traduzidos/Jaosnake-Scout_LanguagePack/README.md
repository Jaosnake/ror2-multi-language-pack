## 🎮 What is Translated
- **Survivor Identity**: Scout ("Force of Nature"), character summary, and survivor tips.
- **Lore Log**: Authentic power plant escape lore log.
- **Outro Messages**: Victory ending (*".. grass grows, birds fly, sun shines and brother, I hurt people ."*) and defeat quote (*"..what the hell was that crap?"*).
- **Full Ability Suite**:
  - **Passive**: Atomic Core (Double jump and Atomic Core charging).
  - **Primary**: Splattergun (scattergun burst), Dastardly Dwarf (high velocity rifle), Elephants Foot (bat bonk).
  - **Secondary**: Toxic Cleaver (blighting & poisoned bat crits), Spike Ball (stunning baseball).
  - **Utility**: Atomic Blast (AOE radial atomic discharge).
  - **Special**: Swap & Ancient Scepter upgrade.
- **Unlocks & Achievements**: Alternate skin and Scout: Mastery achievement (*"As Scout, beat the game or obliterate on Monsoon."*).

## 📥 Installation
1. Install [Thunderstore Mod Manager](https://www.overwolf.com/app/Thunderstore-Thunderstore_Mod_Manager) or [r2modman](https://github.com/ebkr/r2modmanPlus).
2. Install **tsuyoikenko-Scout** and **RiskofThunder-R2API_Language**.
3. Install **Jaosnake-Scout_LanguagePack**.
4. Launch the game in your preferred language!

## Scout formatting compatibility

This pack includes `ScoutFormatFix.dll` to format Scout skill values from the mod configuration and localize the Agile and Atomic Crits tooltips. Keep it installed with this translation pack. P.E.L.E is optional for standard game languages.
