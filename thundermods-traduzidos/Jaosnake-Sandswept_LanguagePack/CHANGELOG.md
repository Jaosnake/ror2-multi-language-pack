# Changelog

## 1.0.5

- Fixed raw placeholder text on Torn Feather and the Shrines of Sacrifice and of the Future across all 15 languages, displaying the actual key (`F`) and default values in-game.
- Updated Brazilian Portuguese translations to better match Sandswept 1.4.6 item descriptions, achievements, and stories.
- Fixed text highlight formatting errors in Korean, Turkish, Simplified Chinese, and Esperanto, and removed unsupported Esperanto diacritics.

## 1.0.4

- Added Thai, Hindi and Arabic translations. Install P.E.L.E 1.0.8 or newer to use them.
- Improved support for item descriptions that change with your settings.

## 1.0.3

- Updated for Sandswept 1.4.6 and improved how item stories and highlights display.
- Added Latin, Esperanto and Latin American Spanish.

## 1.0.2

- Fixed accented characters and text that was still appearing in English.

## 1.0.1

- Fixed credits appearing inside the game interface.
