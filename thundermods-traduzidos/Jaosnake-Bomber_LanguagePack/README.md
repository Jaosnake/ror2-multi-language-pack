## 🎮 What is Translated
- **Survivor Identity**: Bomber ("Heavy Ordinance"), overview, and tactical tips.
- **Outro & Lore**: Full Unit 88 field ordinance report and victory/defeat outro texts.
- **Passive & Keyword**: Lightweight (reduced gravity and air control).
- **Full Ability Suite**:
  - **Primary (M1)**: Micro Missiles
  - **Secondary (M2)**: Concussion Grenade
  - **Utility**: Blast Jump
  - **Special**: Nuclear Strike (including cast message & critical blast banner)
  - **Equipment**: Anti-Air Battery (Name, Pickup, Description, and Lore)
- Translation covers the included Bomber tokens and was compared with the mod’s texts.

## 📥 Installation
1. Install [Thunderstore Mod Manager](https://www.overwolf.com/app/Thunderstore-Thunderstore_Mod_Manager) or [r2modman](https://github.com/ebkr/r2modmanPlus).
2. Install **Dragonyck-Bomber** and **R2API_Language**.
3. Install **Jaosnake-Bomber_LanguagePack**.
4. Launch the game in your preferred language!
