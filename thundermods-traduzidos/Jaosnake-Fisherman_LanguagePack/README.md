## 🎮 What is Translated
- **Character Bio & Subtitle**: Fisherman ("Sickly Poacher"), survival tips, and character description.
- **Lore Log**: Incident report from UES Safe Travels Brig Logs.
- **Outro Messages**: Outro victory flavor (*"..and so he left, with what little time he had."*) and failure (*"..and so he vanished, lost at sea."*).
- **Full Ability Suite**:
  - **Passive**: The Hooks!
  - **Primary**: Debone
  - **Secondary**: Cast
  - **Utility**: F153 Mobile Shanty Platform, Direct Platform, Strange Friend, Junior, and Fisherman's Friend minion tags.
  - **Special**: Man o' War and Steady The Nerves.
- **Keywords**: Treasure, Non-Lethal, Tether, Soulbound, Directable, Smackable, Regenerative, Unfinished.
- **Unlocks & Achievements**: Mastery skin ("Alternate") and Mastery achievement (*"Fisherman: Mastery"*).

## 📥 Installation
1. Install [Thunderstore Mod Manager](https://www.overwolf.com/app/Thunderstore-Thunderstore_Mod_Manager) or [r2modman](https://github.com/ebkr/r2modmanPlus).
2. Install **Wunt-Fisherman** and **R2API_Language**.
3. Install **Jaosnake-Fisherman_LanguagePack**.
4. Launch the game in your preferred language!
