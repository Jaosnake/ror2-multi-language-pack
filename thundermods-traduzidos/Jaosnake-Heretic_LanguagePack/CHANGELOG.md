# Changelog

## 1.0.5
- Updated compatibility for Heretic `1.2.11` and added Esperanto (`eo`) and Latin (`la`), expanding coverage to 15 languages (optional [P.E.L.E](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) enables Ukrainian, Esperanto, and Latin in-game).
- Translated Heretic's achievement and unlockable title across all non-English languages, aligned in-game debuff names (such as Ruin) with each official game language, and fixed a missing unlockable title display.
- Updated the package to use the standard multi-language translation icon and refreshed the documentation.

## 1.0.4
- Reviewed all 13 included languages against the original Heretic 1.2.10 text.
- Corrected Heretic's name, the blade sphere's root effect, and Ruin's 300% base damage plus 120% per stack.
- Reviewed Mark of Heresy stats, pickup text, and unlock requirements; preserved the English achievement name.
- Validated JSON syntax, UTF-8, token keys, placeholders, and formatting tags.

## 1.0.2
- Fixed icon.
- Fixed mojibake, accent issues, language tokens, and untranslated English fallbacks.
- Rebuilt the R2API.Language package for manual Thunderstore upload.

## 1.0.0
- Initial multi-language R2API.Language pack for Heretic.
