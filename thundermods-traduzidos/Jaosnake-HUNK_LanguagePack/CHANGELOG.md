# Changelog

## 1.0.3
- Updated translations for **HUNK 1.5.3**, adding full coverage for all 36 weapons, weapon attachments, interactable weapon cases, inspection texts, and Nemesis lore.
- Corrected outdated skill, passive, virus sample, and achievement descriptions (including the W-870 passive, Mayhem Mode, and Scepter Uroboros effect) and restored missing text highlights.
- Added Esperanto (`eo`) and Latin (`la`) via optional [P.E.L.E](https://thunderstore.io/c/riskofrain2/p/Jaosnake/PELE/) support, expanding the pack to 15 languages and removing duplicate legacy files.

## 1.0.2
- Fixed mojibake, accent issues, language tokens, and untranslated English fallbacks.
- Rebuilt the R2API.Language package for manual Thunderstore upload.

## 1.0.1
- Fixed credits that were polluting the interface due to an error during file upload.
