## ✨ Destaques da Tradução Dedicada
- **289 tokens** 100% traduzidos, revisados e adaptados para o português brasileiro.
- Correção de bugs de tags herdados do mod original (`<style=cShrine>...</color>` corrigido para `</style>`).
- Sanitização de aspas duplas e formatação de texto em todo o lore (incluindo Red Spring Water).
- Mantém nomes de itens, mecânicas e termos fiéis ao universo do Risk of Rain 2.

## 📥 Instalação Manual
1. Instale **Sandswept** e **R2API_Language**.
2. Baixe este pacote.
3. Copie a pasta `Jaosnake-Sandswept_ptBR_LanguagePack` para `BepInEx/plugins/`.
4. No jogo, selecione **Português (Brasil)** nas opções de idioma.

Este pacote contém apenas arquivos de tradução R2API.Language. Ele não modifica o código do Sandswept.
